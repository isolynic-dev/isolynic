So you do **not** need to change the queue logic. You only need to correct the import location.

### 1. Find this exact import block



The important thing is **not to add those properties manually to another `OpportunityDoc` type**. You already have the correct definition in `types/recovery`; the hook was simply importing the wrong type.
